# 臨床回答の用語・表現添削メモ

Chabotとrag_sourceで共有する正本。文献的な正誤の辞書ではなく、ユーザーが指定した表現と適用範囲を保存する。医学的に異なる概念を一括置換しない。

## 2026-11-02：assessment回答の添削（ユーザー確認済み）

出所：Chabotの「初回の評価は何を見る？」に対する回答例へのユーザー添削、および「その方針で修正を実行して下さい」。対象：専門職向けassessment回答、同種のRAG解説・プロンプト編集。原文引用・文献の数値や定義は対象外。

### 表現方針

- 読み手は専門知識を持つ。専門用語の基礎説明を増やさず、専門用語以外は短く自然な日本語にする。
- 情報密度を高くし、何を見るか、所見から何を考えるか、評価を選ぶ理由を具体的に書く。
- Chabot assessmentは約500字（目安450〜550字）、要約→評価①②③最大3項目→理由の3段落を維持。この文字数・構成をRAG資料全体へ適用しない。
- この回答例では座位・背臥位などの姿勢指定は不要。個別の検査手順や原資料にある、検査成立に必要な肢位まで機械的に削除しない。

| 添削前 | 採用表現・書き方 | 適用上の注意 |
| --- | --- | --- |
| 疼痛の刺激性 | 疼痛の種類の特定 | 初回評価の説明での表現選択。医学的同義語と断定しない |
| 症状再現条件 | 症状の再現性 | 条件そのものを説明する必要があるときは具体的な動作等を残す |
| 発症時期・契機 | 発症の時期や経緯 | 問診の説明 |
| 損傷評価 | 損傷部位の評価 | 急性外傷の評価 |
| 術式別制限 | 侵襲による症状 | 今回の術後評価の焦点を変更。実際の動作制限・禁忌と同義ではないため必要時は別に示す |
| 負荷許容性 | 症状の全体像の把握／病期の判別 | 文脈に応じて選ぶ。負荷量の具体的指示をこの語へ一括置換しない |
| 関与の相対的重み | どの組織が関係するか | 原因の可能性を断定しない |
| 仮説を更新する | 介入後の反応から見直す | 介入反応による再評価の説明 |

最後の2件は助手の修正案をユーザーが方針として承認したもの。その他の置換・姿勢省略はユーザーの直接指定。回答例自体を最終承認済みの標準回答とは扱わない。

## 2026-11-13：assessment回答の学習継続性（ユーザー確認済み）

出所：学生・新卒にも読みやすく、勉強意欲のある人に長く使ってもらうためのassessment回答プロンプト案に対する、ユーザーの「プロンプト差し替えを行いデプロイ実行して下さい」。対象：Chabot assessment専用プロンプトと同プロンプトの回帰テスト。RAG資料、他の質問種別、医学的根拠の内容は対象外。

### 表現方針

- 読み手は学生・新卒を含む専門職とし、基本的な専門用語の説明は増やさない。一方で、専門用語の連続で評価から判断への途中を省略しない。
- 評価項目は最大3項目とするが、説明が浅くなる場合は2項目に絞る。項目数より、何を区別する評価かを理解できることを優先する。
- 各項目には評価の目的と、所見からどの候補を考えやすくなるかを一続きで示す。第3段落では最重要の判断を「所見→考えられる状態→次に確認すること」で説明する。
- 評価や推論の不足を指摘するときは、評価語だけで終えず、不足所見と次の確認項目を具体的に示す。

## 追記方法

新しい添削は日付、対象プロジェクト・回答種別、添削前、採用表現、理由・例外、出所（ユーザー発言またはファイル）、確認状態を付けて追記する。助手だけの提案は「未確認」とし、自動適用しない。既存ルールと矛盾する新指示は適用範囲を確認し、旧記録を残して後継を明記する。
